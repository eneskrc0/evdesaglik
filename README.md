| Klasör | Kim | İçerik |
|---|---|---|

Hasta/çalışan arayüzü için: `efehan/web/dist/kapida.html`. Ayrıntılar: [efehan/README.md](efehan/README.md).

GitHub'ı nasıl kullanacağımız: [GITHUB_KULLANIMI.md](GITHUB_KULLANIMI.md).
