# Ekip için GitHub kullanımı (kısa)

Depo: https://github.com/eneskrc0/evdesaglik — herkesin asistanı (Claude, ChatGPT) aynı dosyaları görür.

## Claude ile (önerilen)
1. claude.ai Ayarlar → Bağdaştırıcılar → GitHub bağlı olsun (bir kez).
2. Sohbette şunu deyin: "eneskrc0/evdesaglik deposunun son hâlini çek, sonra şunu yap…"
3. İş bitince: "değişiklikleri depoya gönder" deyin. Claude ayrı bir dal açıp birleştirme isteği (Pull Request) oluşturur.
4. GitHub'da **Pull requests** sekmesinden isteği açıp **Merge pull request**'e basan değişikliği ana dala alır.

## Kurallar
- Herkes kendi klasöründe çalışır: `enes/` (Enes) · `efehan/` (Efehan). Başkasının klasörünü değiştirecekseniz önce haber verin.
- Her klasörün kuralları ve son durumu kendi `CLAUDE.md` / `AGENTS.md` dosyasında. Önemli bir karar alındığında oraya bir satır eklenir.
- Bir şey bozulursa GitHub her eski hâli saklar; geri dönülebilir.

## Elle (Claude olmadan)
- Görmek için: GitHub sitesinde klasörlere tıklayın.
- Dosya eklemek için: klasörde **Add file → Upload files**, dosyaları sürükleyin, altta kısa bir açıklama yazıp **Commit changes**.
